# Working on this repo

## Git
- Commit frequently: one small, focused commit per logical change, pushed as you go.
- Evan is the sole author of every commit. Before committing, set
  `git config user.name "Evan"` and `git config user.email "evanchen0609@gmail.com"`.
- Never add `Co-Authored-By`, `Claude-Session`, or any other attribution trailer to commit messages.
- Name branches after the change (`feature/…`, `fix/…`, `docs/…`), not auto-generated names.
- Base work on the `update` branch. Pushing to `update` deploys the site to evanchen.info; `main` is stale.
